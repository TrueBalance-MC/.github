TrueBalanceMC is a Minecraft Server themed around the Avatar the Last Airbender franchise. This Github organization is the organization responsible for the development side of the server, primarily consisting of forks of existing plugins and original plugins made solely for the server not released to the public.

The server is notable due to its variety of original features and mechanics, constant active development, and a __complete lack of Pay-to-win mechanics__. For more details on the server, check out our Website (Website still in progress).

The server is currently not open to the public, but is gearing up for a __Public Beta__. If you are interested in participating in said public beta, join our [Discord Server](https://discord.gg/TbYS2hnvgM).

__TrueBalance MC is NOT affiliated with Nickelodeon, Paramount, Avatar Studios, or any other organization involved with the Avatar the Last Airbender Franchise in any official capacity__

# Plugins

TBMC Features a variety of original plugins. The ones you will find attached to this Organization are not intended for use outside of the TBMC Server, and will likely require extensive edits to be made to work on other servers.

Some plugins made for the server ARE available to the public, however. Check [Miden's Modrinth Porfile](https://modrinth.com/user/Miden) for a series of plugins made for the server that are currently available for public use.
